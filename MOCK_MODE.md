# Mock Mode for Portfolio

Run MiniGlean completely offline with pre-loaded demo data - **no API keys needed!**

Perfect for:
- Portfolio screenshots
- Demo recordings
- Testing the UI
- Showing the concept without costs

## What's Different in Mock Mode?

| Feature | Mock Mode | Real Mode |
|---------|-----------|-----------|
| OpenAI API | ❌ No calls | ✅ Real AI |
| Responses | Pre-written | Generated |
| Embeddings | Random vectors | Real embeddings |
| Documents | Pre-loaded (3 docs) | Upload your own |
| Cost | $0 | ~$0.10 for demo |
| Setup time | 2 minutes | 3 minutes |

## Quick Start

Just run:

```bash
./mock-mode-setup.sh
```

That's it! The script will:
1. Start PostgreSQL with pgvector
2. Start the FastAPI backend (mock mode)
3. Start the Next.js frontend
4. Run database migrations
5. Load 3 demo documents with mock embeddings

Then open **http://localhost:3000**

## How Mock Mode Works

### Backend (apps/api/)
- **config.py**: Reads `USE_MOCK_LLM=true` from environment
- **services/agent_mock.py**: Returns pre-written responses based on keyword matching
- **services/embedder.py**: Generates deterministic random vectors instead of calling OpenAI
- **services/chat_service.py**: Routes to mock agent when `USE_MOCK_LLM` is enabled

### Data
- **mock_data.sql**: SQL file with 3 documents and 11 chunks
- Each chunk has a 1536-dimension vector (random, but deterministic based on content hash)
- All document metadata matches what the demo seed script would create

### Docker
- **docker-compose.mock.yml**: Modified docker-compose with `USE_MOCK_LLM=true`
- Mounts mock_data.sql into the database container
- Uses separate volume (`pgdata_mock`) so it doesn't conflict with real mode

## Limitations

1. **No real uploads** - you can't add new documents in mock mode (the UI will work, but embeddings will be random)
2. **Fixed responses** - answers are pre-written, not generated by AI
3. **Simple keyword matching** - agent just pattern-matches questions to canned responses
4. **No actual RAG** - doesn't do real vector similarity search (though it could with the random embeddings)

## Switching to Real Mode

To use real OpenAI:

1. Stop mock mode: `docker-compose -f docker-compose.mock.yml down`
2. Get an API key from https://platform.openai.com/api-keys
3. Follow PORTFOLIO_QUICKSTART.md or run `./portfolio-setup.sh`

## Troubleshooting

**"Database already exists" or data doesn't load**

```bash
# Full cleanup
docker-compose -f docker-compose.mock.yml down -v
./mock-mode-setup.sh
```

**Port already in use**

Make sure you don't have the real mode running:
```bash
docker-compose down
```

**Services won't start**

Check Docker is running and has enough resources:
- Memory: at least 4GB
- Disk: at least 2GB free

View logs:
```bash
docker-compose -f docker-compose.mock.yml logs -f
```
